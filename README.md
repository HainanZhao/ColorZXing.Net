## How color carries more

| 01 · Split | 02 · Compose | 03 · Share |
|---|---|---|
| Text is balanced across three UTF-8 QR payloads. | Binary modules are mapped onto blue, green, and red planes. | The decoder finds geometry once and samples every channel together. |

Each color plane remains a regular QR symbol with its own error correction. Together, the planes can carry up to roughly three times the payload of a comparable black-and-white symbol under ideal conditions.

## Need even more room?

Set `compressed: true` to add lossless managed LZ compression and a checksum-protected binary frame before the same three RGB layers are created. It uses the same eight colors and the same QR error correction, so the extra capacity does not depend on adding harder-to-distinguish color shades.

```csharp
var info = ColorZXingRGB.AnalyzeCompression(largeJson);
using var qr = ColorZXingRGB.Encode(largeJson, 400, 400, 4, compressed: true);
string decoded = ColorZXingRGB.Decode(qr, compressed: true);
```

Repeated text, JSON, XML, and structured records can shrink dramatically; encrypted, compressed, or random data usually cannot. When compression does not help, the format stores the UTF-8 bytes unchanged. The same flag is available on the RGBA methods used in browsers.

Compressed symbols use a separate wire format, so pass `compressed: true` while decoding them. The versioned frame validates layer order, payload length, and CRC-32 before returning data.

## True 6-bit spectrum muxing

`ColorZXingHighDensity` multiplexes **six** binary QR layers—two in each red, green, and blue channel. Every channel uses four evenly spaced intensity levels (`0`, `85`, `170`, `255`), producing a 64-color alphabet and six raw bits per module instead of three.

```csharp
using var qr = ColorZXingHighDensity.Encode(largeMessage, 600, 600, 4);
string decoded = ColorZXingHighDensity.Decode(qr);
```

The decoder estimates black and white references independently for each channel, normalizes channel gain and white balance, then maps samples to the nearest intensity level. The payload is also compressed when that helps, so structured text can gain from both spectrum muxing and fewer input bytes.

This mode offers roughly twice the raw channel capacity of regular RGB, but four intensity levels leave less noise margin than two. Use a generous module size, lossless PNG when possible, and test the actual camera, display, printer, and lighting path. High-density symbols require `ColorZXingHighDensity.Decode`.

## Start in seconds

```sh
dotnet add package ColorZXing.Net
```

```csharp
using ColorZXing;
using System.Drawing.Imaging;

const string message = "More room for text, JSON, 中文, and 😀";

using var qr = ColorZXingRGB.Encode(message, width: 400, height: 400, margin: 4);
qr.Save("color-qr.png", ImageFormat.Png);

string decoded = ColorZXingRGB.Decode(qr);
```

That same decoder accepts a `Bitmap`, encoded PNG/JPEG bytes, or a `Uri`. For browser and canvas apps, the RGBA APIs avoid `System.Drawing` entirely:

```csharp
ColorZXingPixelData image = ColorZXingRGB.EncodeRgba(message, 400, 400, 4);
string decoded = ColorZXingRGB.DecodeRgba(image.Pixels, image.Width, image.Height);
```

## Built for the RGB format

- **Unicode-aware** — payloads are balanced by UTF-8 size without splitting characters.
- **One shared scan** — finder detection and perspective sampling are reused across all three planes.
- **Fast on the CPU** — channel payloads are processed concurrently; no GPU is required.
- **Browser-ready** — platform-neutral RGBA buffers power the live WebAssembly demo.
- **Backward-compatible decoding** — older ColorZXing RGB symbols fall back to independent channel scans.

On the project benchmark—a 400×400 image with 200 ASCII characters—the shared pipeline encodes in **3.08 ms** and decodes in **2.53 ms**. See the [benchmark methodology and algorithm notes](https://github.com/HainanZhao/ColorZXing.Net/blob/master/PERFORMANCE.md) for context and limitations.

## Know before you ship

RGB symbols require `ColorZXingRGB.Decode`; a conventional grayscale scanner sees only a mixture of the three layers. Prefer PNG when you control storage. JPEG compression, printing, lighting, white balance, and camera color mixing can reduce channel separation, so test with the capture conditions your product will use.

For reliable detection, keep a four-module quiet zone. The requested width and height are minimums—the result may grow when the QR version needs more modules.

The `Bitmap` API uses `System.Drawing.Common` and is best suited to Windows. Web, mobile, and other image stacks can use the RGBA APIs and supply pixels through their native image or canvas layer.
